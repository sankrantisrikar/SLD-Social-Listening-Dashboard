## Fastest Path to Real Data

### Step 1: Reddit (0 minutes - No API needed!)
✅ **Works immediately** - Just select Reddit platform and go!
✅ **Real data** - No demo, actual Reddit posts
✅ **No authentication** - Public data access

### Step 2: YouTube (5 minutes - Free)
1. Go to https://console.cloud.google.com/
2. Create project → Enable "YouTube Data API v3"
3. Create API Key
4. Paste in dashboard

### Step 3: LinkedIn (5 minutes - Free trial)
1. Go to https://console.apify.com/sign-up
2. Get free trial (5,000 credits)
3. Copy API token from https://console.apify.com/account/integrations
4. Paste in dashboard

**You're done!** You now have 3 platforms with real data.

## Troubleshooting

**"Failed to fetch data"**
- Check API key is correct
- Verify platform is enabled
- Check browser console (F12) for errors

**"Rate limit exceeded"**
- Wait for quota reset (usually daily)
- Upgrade to paid tier
- Use fewer platforms simultaneously

**"No data returned"**
- Check date range (last 8 weeks)
- Verify search keywords match your content
- Try different platform
