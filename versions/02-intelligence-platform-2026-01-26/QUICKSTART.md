# Quick Start Guide

## 🚀 Get Started in 2 Minutes

### Step 1: Open the Platform
```bash
# Simply open index.html in your browser
open index.html
```

Or double-click `index.html` in your file explorer.

### Step 2: Select Platforms
Click on one or more platform checkboxes:
- ☐ LinkedIn
- ☐ X (Twitter)
- ☐ Reddit  
- ☐ Podcasts / YouTube
- ☐ News / Policy

### Step 3: View Dashboard
The unified dashboard will automatically load showing:
- CEO Executive Summary
- Key Metrics
- Trend Charts
- Sentiment Analysis

### Step 4: Ask Questions
Use the AI Chat Assistant on the right to ask questions like:
- "Why did prior auth mentions spike last week?"
- "Which payers have the most negative sentiment?"
- "What are the top 3 risks this week?"

## 💡 Tips

### Best Practices
- **Start with one platform**: Test with LinkedIn first
- **Define clear questions**: What decisions will this inform?
- **Set expectations**: Demo data vs real data
- **Iterate quickly**: Gather feedback early and often
