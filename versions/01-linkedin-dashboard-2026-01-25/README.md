# LinkedIn Pain Management Intelligence Dashboard

**Automatic keyword-based LinkedIn search and analysis for U.S. interventional pain management.**

## 🎯 What It Does

1. You enter keywords (e.g., "prior authorization pain management")
2. System automatically searches LinkedIn
3. Fetches all matching posts and profiles
4. Displays results in beautiful dashboard
5. Click any link → Opens directly on LinkedIn

## 📁 Files

- **linkedin-pain-management-dashboard.html** - Demo version (no setup, sample data)
- **linkedin-dashboard-auto.html** - Live version (auto-searches LinkedIn)
- **SIMPLE_SETUP.md** - Complete setup instructions

## 🚀 Quick Start

### Option 1: See the Demo (0 minutes)
```
Open: linkedin-pain-management-dashboard.html
```
Beautiful dashboard with sample data. No setup required.

### Option 2: Live LinkedIn Search (5 minutes)
```
Open: linkedin-dashboard-auto.html
```

**You need:**
1. Apify API token (free trial: https://console.apify.com/sign-up)
2. LinkedIn cookie (Press F12 → Application → Cookies → Copy "li_at")

**Then:**
1. Enter your credentials
2. Enter keywords (pre-filled with pain management terms)
3. Click "Start Auto Search"
4. Wait 30-60 seconds
5. View results!

## ❓ Need Help?

**Getting LinkedIn cookie:**
```
Browser → F12 → Application → Cookies → linkedin.com → Copy "li_at" value
```

**Common issues:**
- "Cookie required" → You must enter your LinkedIn li_at cookie
- "Invalid cookie" → Get fresh cookie (log into LinkedIn again)
- "No posts found" → Try different keywords
