STEP 2: Get Real LinkedIn Data (5 minutes)
  
  A) Get Apify Token:
     → https://console.apify.com/sign-up (free trial)
     → Copy your API token
  
  B) Get LinkedIn Cookie:
     → Open linkedin.com (logged in)
     → Press F12
     → Application → Cookies → linkedin.com
     → Copy "li_at" value
  
  C) Run Search:
     → Open: linkedin-dashboard-auto.html
     → Enter token + cookie
     → Keywords are pre-filled!
     → Click "Start Auto Search"
     → Wait 30-60 seconds
     → View results!
